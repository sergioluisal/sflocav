# SF Locação — GitHub Pages

Site estático da SF Locação preparado para **GitHub Pages**.

## Estrutura

```text
sf-locacao.github.io/
├── index.html
├── style.css
├── script.js
└── assets/
    └── sf-banner.png
```

## Publicar no GitHub Pages

O nome ideal do repositório é:

```text
SEUUSUARIO.github.io
```

Depois:

1. Crie o repositório no GitHub com esse nome.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Salve.
6. O site ficará disponível em:

```text
https://SEUUSUARIO.github.io/
```
